## 为什么合并

标注者的成对判断本来就有**三种**结果，而之前的主检验只测其中一种：

```
某张赢      78 对   45%   ← 只有这一档进过主检验
一样好      47 对   27%
都不要      49 对   28%
           ────
           174 对
```

分成两套考题是我最初的做法。它的代价是主检验只覆盖 45% 的判断，
而「都不要」那 49 对在**任何一轮里都没被判过分**。

合并的代价：答案空间从 3 变 4，R2 那 900 次数据全部不可复用 ——
那些调用问的是不同的问题。换来的是覆盖率 45% → 100%、
功效（+15pt）53% → 84%。

## 任务

一次给模型两张照片，四选一：

```
JIA      甲更值得留
YI       乙更值得留
TIE      两张都好，但分不出高下
NEITHER  两张都不值得留
```

**TIE 和 NEITHER 是不同的答案。** 以前只有三个格子，
「都不要」只能塞进 TIE —— 这一轮要看的正是模型分不分得开。

## 主指标

**总准确率** = 答案与标注者一致的对数 / 174。

判对的定义（严格，不给部分分）：

| 真值 | 只有这个算对 |
|---|---|
| 某张赢 | 答对应的那张（AB/BA 双向一致） |
| 一样好 | TIE |
| 都不要 | NEITHER |

**答 TIE 不能顶替 NEITHER，反之亦然。** 它们表达的是不同判断：
TIE 是「分不出」，NEITHER 是「都不够格」。互相顶替算错。

⚠️ **双向不一致（翻覆）在任何真值下一律算错，包括真值 = 一样好。**

这一条不是从前几轮沿用的，是 2026-09-03 修掉的一个计分缺陷：

```
原来   翻覆 → winner 记成 'tie'
       而同层档真值就是 'tie'  →  判对
后果   「答对率」恒等于「1 − 双向一致率」，三组逐个吻合
       判对的 37/36/43 对里，真正两次都主动答平局的只有 1/1/2 对
       那一档没有测到任何关于平局识别的东西，还反过来**奖励不稳定**
```

现在 `winner` 有五个值：`a / b / tie / neither / inconsistent`。
`tie` 只表示「两个方向都**主动**答了平局」，翻覆记 `inconsistent`，
它在任何真值下都判错。

**这会让分数明显变低** —— 对照组同层档从 51.4% 掉到约 1.4%。
那个降幅才是它实际的平局识别能力，**降幅本身要写进报告**，
否则看惯旧数的人会以为出了 bug。

## 必须同时报的分层

总分一个数会把三种可靠度不同的真值混在一起，所以**总分 + 三层，一起报，缺一不可**。

| 层 | 对数 | 真值可靠度 |
|---|---|---|
| 某张赢 | 78 | 方向重测一致 **90.5%** ← 最可靠 |
| 一样好 | 47 | 判平重现约 **61%** |
| 都不要 | 49 | **未单独测过重测信度** ← 最弱，只当探索性 |

**「都不要」那一层的任何结论都要带上「其真值可靠度未知」这句。**

---

## 混淆矩阵（必报）

`模型答的` × `真值`，3×3。要看的是两个格子：

```
真值=一样好，模型答 NEITHER    → 它把「都挺好」当成了「都不够格」
真值=都不要，模型答 TIE        → 给了格子它也不用
```

**第二个格子尤其关键。** 如果模型大量用 TIE 顶替 NEITHER，
结论是「给了它表达能力它也不用」，而不是「它没有表达能力」——
这两个结论对下一步的动作完全不同。

## 随机基线（合并之后变了，必须写明）

```
四选一等概率乱猜         25%
永远猜「甲赢」            78/174 = **44.8%**   ← 真正该比的那条线
```

真值分布不均（78 有赢家 / 47 一样好 / 49 都不要），所以
**一个 40% 的总分不是「比随机好」，是还不如永远猜甲赢。**
报告里两条基线都要给出，否则必然被误读。
