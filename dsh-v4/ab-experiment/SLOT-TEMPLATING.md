# 模型在约三分之一的题上不是在判断，是在填模板

2026-09-03 实测，用 R2（`20260903-0245`）的数据。
这是这一轮最重要的发现，比锚点那条严重。

## 问题是怎么提出来的

标注者问：会不会模型两次给的其实是**同一张照片、同一个理由**，
只是我们的位置映射把它算成了不一致。

## 判别检验

同一对问两遍，第二遍两张照片对调。`甲` 永远指排在前面的那张。

把 AB 的理由里 `甲`↔`乙` 对调之后，再跟 BA 的理由比：

- 模型若跟着**内容**走：对调后应当更像 BA（同一张照片同样的描述，只是换了名字）
- 模型若跟着**位置**走：不对调就已经很像（描述的是槽位，不是照片）

在「两次答了同一个槽位」的那批对上：

```
组          对数   原样相似   甲乙对调后   结论
无提示        30    0.390     0.332     跟位置走
仅规则        25    0.466     0.379     跟位置走
规则加范例     28    0.448     0.301     跟位置走
```

**三组一致：对调之后反而更不像。模型描述的是槽位，不是照片。**

## 实例

```
DSCF7824 vs DSCF7821，两次都答「甲」，而甲是两张不同的照片
  第一遍  甲=7824：「甲眼神更有神、更聚焦，乙眼神略显涣散无神」
  第二遍  甲=7821：「甲眼神更集中有神…乙眼神略涣散。」

DSCF7666 vs DSCF7669，两次都答「乙」
  第一遍  乙=7669：「乙眼睛睁开到位、眼神有落点；甲明显半眯、无神」
  第二遍  乙=7666：「乙的眼神更到位、睁开程度更好；甲眯眼且眼神无落点」
```

同样的话，给了槽位里的任何一张，**连用词都一样**（「涣散」「无落点」）。

## 结论

**我们的位置映射没有错。** 模型确实给出了不同的照片 —— AB 答甲选到 a、
BA 答甲选到 b，那是两张不同的照片，判「不一致」是对的。

**但标注者的直觉指向了更深的一层：** 模型在这些对上根本没有在判断。
它输出的是一个按槽位填的模板，而理由字段读起来具体、流畅、有说服力，
实际不携带任何关于照片的信息。

```
无提示     30/78 = 38%
仅规则     25/78 = 32%
规则加范例  28/78 = 36%
```

**约三分之一的题，测的不是「模型判得准不准」，是「模型会不会套模板」。**

## 这解释了什么

- 双向一致率贴着 50% —— 模板化必然产生不一致（总答同一槽位 → 两次不同照片）
- 准确率接近随机 —— 三分之一的题没有信息量
- 锚点没有提升 —— 在套模板的题上，给什么提示都不会改变输出

## 这**不**解释什么

「模板化集中在差别细微的对上」这个解释**没有站住**。
按睁眼差中位数比较模板化的对与其余对：

```
无提示     0.030 vs 0.023   ← 反方向
仅规则     0.023 vs 0.030
规则加范例  0.012 vs 0.041
```

三组方向不一致，n≈25 的中位数太噪。**模板化确实存在，但触发条件未知。**

## 对产品的直接含义

如果打算把模型的理由展示给用户看（「为什么选这张」），
**在这三分之一的题上那段理由是编的** —— 而且用户看不出区别，
因为它和真实判断的理由长得一模一样。

在弄清触发条件之前，理由字段不应该直接对用户展示。

## 对实验的直接含义

判据不改：模板化表现为「不一致」，而不一致一律算错 —— 这个处理是对的。

但结论的措辞要改：不能写「模型判断不稳定」，
要写「**约三分之一的题模型没有在判断，其余题上它的表现是 X**」。
这两句话对下一步的动作完全不同。
