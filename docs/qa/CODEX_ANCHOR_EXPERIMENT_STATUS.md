# Codex 人像锚点实验：独立方案，待实验验收

这是 Codex 原本实现的实验分支。它与 main 的 Claude 实现是两个独立方案；本 PR 用于审阅和记录，
不表示允许合并。最终由仓库所有者根据实验结果决定是否合并 main。

## 实验设计

在相同候选池、目标数量、会话模型和预算下比较：

| 组别 | 全池 low | high / pairwise / 独立审计 |
|---|---|---|
| A | 原 baseline | 原 baseline |
| B | 新文本 rubric | 新文本 rubric |
| C | 与 B 相同 | 文本 rubric 与视觉锚点 |

所有组都经真实 DSH preset 运行，所有视觉调用继承当前会话 provider/model。
运行时锚点包与原照片只留在本地，不进入 PR。独立 evaluator 隔离 selector 的评分与选择理由。
最终 exact-K 和独立审计完成后才进行隔离的人工 pick 对照；低于约定的 90% 必须如实报告。

## 截至 2026-09-06 的真实结果

这部分是传输与恢复能力验证，尚不是 A/B/C 选片效果结论。

- 309 张候选；K=20；运行锚点与候选的精确内容重合为 0。
- 实际测试会话选择 MiniMax-M3；该选择不是插件的默认模型。
- v2 字符串信封在首张图片上返回不可解析结果，有效评分为 0。
- v3 自由对象信封的无图探针发现多个空数组字段返回非数组。
- v4 完整类型对象信封通过 A 的两项无图合同测试；真实首批 11 次图片请求中，10 次评分被接受，
  第 11 次因信封字段不符合约定停止。10 条成功结果已保存，没有取得最终 20 张或 overlap。

不得把 10/11 的格式接受数写成选片准确率，也不能据此推断整批稳定性。

## 当前代码中的修复

- 工具声明带完整 result 字段类型，避免在字符串中再嵌套转义 JSON。
- nonce、信封结构和领域评分校验保持严格；错误诊断仅输出已知字段路径和类别。
- 收到明确格式拒绝时记录失败；同一操作最多两次总尝试，恢复只能发生在下一 turn。
- 网络结果未知的操作继续阻止自动重发；旧 checkpoint 不会被偷偷改为成功或删除。

追加的恢复修复已通过离线测试，尚未替换产生上述 10 条结果的运行快照。后续须验证升级迁移能保留
有效评分的完整身份与计费证据，再开始完整对照实验。不能通过换 seed 重买整批来冒充恢复。
