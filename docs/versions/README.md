# 版本演进

> 📌 **每一版都有 tag 和 GitHub Release,可以直接 checkout 到那一刻的完整代码。**
> 对照表见 [TAGS.md](TAGS.md)。`main` 分支刻意保持不动。

这个目录记录每一版**当时是怎么想的**、**做了什么**、**最后测出来是什么结果**。

保留失败的版本不是为了存档，是因为这个项目里最有价值的产出恰恰来自一次失败：
第三版花了 997 次付费调用，证明了「让视觉大模型给照片打分」这条路在这个任务上等于掷硬币。
没有那 997 次，第四版就没有理由把主干挪到本地。

## 一句话总结这五版

v1 问「这张照片有没有毛病」，v2 问「模型觉得这张几分」，
v3 把 v2 的分数用一整套审计机制包起来，
v4 发现**问题出在分数本身**、于是换了产生分数的方式，
v4.1 发现**连「什么算好」都得先问一句**，
v4.2 发现**最强的先验是用户自己怎么挑** —— 让输出的形状去匹配他的行为，
比继续改进打分有效得多。

> v4 的文档保持原样未改，包括那些后来被推翻的主张。
> 只看结论看不出「一个看起来很有道理的想法是怎么被自己的数据否掉的」，
> 而那个过程是这个项目最有价值的产出。
