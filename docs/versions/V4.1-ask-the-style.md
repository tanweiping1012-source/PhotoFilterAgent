# v4.1 · 不要正样本，问一句就够了

> 2026-08-30。这一版没有新算法。它做的全部事情是**把 v4 的几条核心主张实测掉**，
> 然后按剩下的证据重新组装。
>
> v4 的原始思路完整保留在 [V4-local-first.md](V4-local-first.md)，一字未改。

---

## 起点：一个提问撕开的口子

v4 在 DSH 上跑通之后，被问了一句：

> **「似乎全程没有 VLM？」**

答案是对的 —— 没有任何 VLM 看过照片。CLIP 是图像编码器不是 VLM，
对话模型只读文本行。v4 的设计里 VLM 本来有位置（只做否决），
但**我只写了设计没实现**，还在架构图里画着那个方框。

顺着这个缺口往下查，v4 的每一条核心主张都塌了一遍。

---

## 塌掉的六条

### ① 我把 v1 免费的能力丢了

v4 的「否决门」里最重要的一项是闭眼检测。而**闭眼检测是 v1 就写好的免费本地能力**
（Apple Vision 给眼睛轮廓坐标，算高宽比，阈值 0.22 实测标定）。
排序主干挪回本地时，连同这层资格门一起扔掉了。

代价：

| | 闭眼张数 |
|---|---|
| v4 选出的 20 张 | **6 张（30%）** |
| 全池基准率 | 8.2% |
| 用户自己挑的 20 张 | **0 张** |

接回来之后：**交付 3/20 → 4/20，p 从 0.1299 到 0.0316** ——
从「跟运气区分不开」跨到「统计显著」，成本为零。

> 教训：**「我们不用 VLM」不等于「不需要 VLM 负责的那件事」。**

### ② 我精心搭的 CLIP 流水线，输给了系统自带的 API

把 v1 那些「被否掉」的本地指标重测一遍：

| 指标 | AUC | 信噪比（照片间σ / 重评σ） |
|---|---:|---:|
| **Apple Vision 人脸质量** | **0.723** | **21.2** |
| CLIP + topiq_nr-face（v4 用的） | 0.606 | — |
| 全局清晰度 | 0.517 | — |
| v3 的六维付费打分 | 0.497 | 0.92 |

**为什么一个端上小 CNN 赢过付费大模型**：
`VNDetectFaceCaptureQualityRequest` 是苹果为「实况照片选关键帧、连拍选最佳」做的，
学的是**「同一张脸的多次拍摄里哪一次更好」**—— 正是我们在问的问题。
通用美学模型学的是「任意图片好不好看」，是另一个问题。

**任务足够窄的时候，任务对口的小模型 > 通用大模型。**

> 它为什么被埋了两个版本：v1 的结论是「本地技术指标和人的口味基本无关」。
> 那句话对清晰度/曝光成立（AUC 0.517），**对人脸质量不成立**（0.723）。
> 一个过度概括的负面结论，埋掉了正确的东西。

### ③ 「确定性」是假的

v4 一直宣称排序是确定性函数。实测连跑三次：AUC 0.715 / 0.704 / 0.696，交付 3 / 4 / 3。

两处根因：

- **分组依赖打分。** 贪心 leader 聚类按分数顺序处理，换打分器就换一套分组。
  改成按文件名顺序 —— 分组是照片本身的属性。
- **Apple Vision 本身不确定。** 同一批扫两遍，106/280 张分数差 1–5 分。
  信号是好的（信噪比 21.2），但前 20 名那条切线对 ±1 分极敏感。
  修法：按数据集指纹缓存。缓存后连跑三次完全一致。

### ④ 核心卖点「从标注学口味」，交付层面没有收益

| 方案 | 交付前 20 命中 | AUC |
|---|---:|---:|
| 忽略标注 | **1.83 ± 0.97** | 0.714 |
| 融合个人口味探针 | 1.57 ± 0.80 | **0.754** |

30 次划分，融合只赢 7 次、打平 13 次、落后 10 次。
**AUC 更高，交付没变好** —— 和之前融合两个通用美学指标是同一个模式。

已默认关闭。代码和测量都留着，因为这个负面结果本身是产出。

### ⑤ 换一批照片，全盘失效

用户自己拿另一趟旅行的照片试了一遍（道东三湖 133 张 / 6 张人工精选）。

| 指标 | 数据集①（人脸） | 数据集②（氛围） |
|---|---:|---:|
| Apple Vision 人脸质量 | **0.723** | **0.455** ← 低于随机 |
| topiq_nr-face | 0.606 | **0.732** |
| laion_aes | 0.583 | 0.491 |

**指标排名完全翻转。没有任何配置在两个数据集上都显著。**

（顺带补上两个之前没验证的：导出的两步确认能用；
导出的 20 张与原图**逐字节一致**，原图未被移动/删除/改名/修改。）

### ⑥ 我差点拿一份有噪声的答案去推翻正确的设计

数据集② 的 6 张金标里有 2 张是闭眼的。我据此判定资格门有害，改成默认关闭。

**然后用户说：「闭眼睛的就是被资格门卡出去，我有时候挑选也会出噪声。」**

那 2 张是手滑。**这是只有用户知道的信息，从实验数据里推不出来** ——
数据能告诉我「金标里有闭眼照」，推不出「那是不是他想要的」。

剔除噪声重算：vision_face 从 0.455 回到 0.571（确实是噪声在拖，但没回到 0.723）。
资格门改回默认开。

> 教训：**人工答案本身也有噪声，而噪声只有出答案的人知道。**
> 改结论要比下结论更谨慎 —— 如果用户没说那句话，错误的版本就留下了。

## 剩下的证据指向一个完全不同的解法

### 不是没信号，是方向反了

把全套美学模型在「按氛围挑」的那批上跑一遍（只保留满覆盖的）：

| 指标 | AUC |
|---|---:|
| clipiqa+ | 0.561 |
| musiq-ava | 0.346 |
| laion_aes | 0.291 |
| nima | 0.260 |
| liqe | 0.220 |
| **topiq_iaa** | **0.114** |

**6 个通用美学模型全部反向。** 用户选的 4 张里，
有 2 张在 laion_aes 上排 **132/133 和 133/133** —— 全池倒数第一、第二。

翻转符号后 `topiq_iaa` 是 **0.886**，`laion_aes` 是 **0.709**。

合理的解释：氛围往往伴随弱光、动态、颗粒、柔焦、逆光 ——
而这些恰恰是技术画质模型要扣分的东西。

### 但真实用户不会先给你正样本

用户指出的关键产品问题：

> 普通用户使用这个 agent 的时候，agent 会要求他先给一批自己觉得好看的照片吗？
> 似乎也不会，所以是不是不需要先去找正样本。

**对。** 真实交互就是一句「帮我从这 500 张里挑 20 张」。
要求先给正样本 = 把最难的一步甩回给用户，而且他还没看过结果，
不知道该给什么范例。（何况实测证明标注在交付层面本来就没收益。）

### 那就问一句 —— 而这正是 agent 存在的意义

| | A 质量优先 | B 氛围优先 | 两套重叠 |
|---|---|---|---|
| 数据集①（按人脸挑） | **4/20  p=0.032 ✅** | 0/20 | **0/20** |
| 数据集②（按氛围挑） | 1/4 | **2/4** | 4/20 |

两套名单几乎不重叠，各自场合下是对方的两倍。**选错方向等于白跑。**

而确定性排序器结构上不可能知道这一趟想要什么，**一句对话就能解决**。

> **这修正了 v4 对 agent 角色的定位。**
> v4 把 agent 定位成「听懂意图、选参数、解释结果」，把解释当成主要价值。
> 实际上最有价值的是**问出标准** —— 那是排序器做不到、而对话天然能做到的事。

## v4.1 当前的形态

```
用户："帮我从这 500 张里挑 20 张"
   ↓
agent 问一句："要拍得清楚好看的，还是有氛围的瞬间？"    ← agent 不可替代的地方
   ↓
本地确定性排序    0 次付费调用 · 几秒 · 同输入永远同输出
   ├─ quality：Apple Vision 人脸质量（AUC 0.723）
   └─ mood：   通用美学分翻转（AUC 0.709，仅 4 张金标支撑）
   ↓
闭眼资格门 → 场景分组（同组最多 2 张）→ 前 N 张
   ↓
20 张 + 每张理由 + 诚实的置信度
   ↓
用户："太糊了" / "太规整了"  →  换一档重排
```

| 默认值 | 依据 |
|---|---|
| `style = quality` | 20 张金标、p=0.032；mood 只有 4 张金标、p=0.11 不显著 |
| 闭眼资格门 **开** | ①净赚 +1；②那 2 张经用户确认是噪声 |
| 个人口味探针 **关** | 交付层面无收益 |
| 冷启动 `vision_face` | 两集偏好相反、均值打平，**只因为证据强度**（20 金标 vs 4 金标） |

## 证据强度一览（这一节是给未来的自己看的）

| 结论 | 支撑 | 强度 |
|---|---|---|
| v3 的绝对打分是噪声（信噪比 0.92） | 重评实测 | **强** |
| 通用美学模型天花板 ~0.6 | 7 个模型一致 | **强** |
| 闭眼资格门有用 | 数据集①，p 从 0.13 到 0.032 | 中 |
| Apple Vision 人脸质量最强 | 数据集①（20 金标） | 中，**②上翻车** |
| 标注学口味无收益 | 30 次划分 | 中 |
| 通用美学在「氛围」场景下反向 | 6 个模型一致，但仅 4 金标 | 中 |
| 两种风格值得让用户选 | 名单重叠 0/20、4/20 | 中 |
| mood 这一档有效 | 2/4，p=0.11 | **弱，不显著** |
| 方案能泛化到第三批照片 | —— | **无证据** |
