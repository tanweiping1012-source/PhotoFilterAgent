# 人像质量：把本地信号榨干之后，天花板在哪

> 2026-08-30。这一轮只做一件事：**把人像这条线做到本地信号的尽头**，
> 然后如实说明剩下的差距需要什么才能补。

---

## 一、诚实的成绩

```
交付前 20 命中     3–4/20（五次 Vision 扫描：4, 4, 3, 3, 4，均值 3.6）
超几何 p 值        0.03 ~ 0.13，五次里三次过 0.05 线
AUC               0.704 ~ 0.744
随机期望           1.29/20
付费调用           0
```

**我之前报的「4/20，p=0.032 显著」是抽样分布的好的那一端。**
真实情况是 3–4/20，大约六成运行能过显著线。波动来源是
Apple Vision 的人脸质量本身不确定（同一批扫两遍，106/280 张分数差 1–5 分），
而前 20 名这条切线对 ±1 分极度敏感。缓存把结果锁定成确定的一次，
但锁定的是哪一次是随机的。

## 三、试过但没用的（全部记录在案）

### ① 「脸够大」不是信号

假设：近景人像更可能被选。实测 —— 92 张大脸照里有 **6 张金标，正好等于随机期望**
（富集 1.0 倍，p=0.58）。用户近景和环境人像都选。

### ② 所有融合都让交付变差 —— 这是第四次

| 打分方式 | AUC | 交付 |
|---|---:|---:|
| **face_quality 单独** | 0.716 | **5/20** ✅ |
| + 睁眼 0.5/0.5 | 0.730 | 3/20 |
| + 睁眼 0.7/0.3 | 0.729 | 4/20 |
| × 睁眼（乘法） | 0.730 | 3/20 |
| + topiq 人脸 0.5/0.5 | 0.680 | 4/20 |
| + laion 0.7/0.3 | 0.712 | 3/20 |
| 三者等权 | 0.702 | 4/20 |

**每一种组合都是 AUC 升、交付降。** 前三次分别是：
laion+topiq 融合、个人口味探针融合、探针+vision_face 融合。
四次独立实验指向同一个结论：**在这个任务上，融合改善中段排序、稀释头部。**

### ③ 多次扫描取平均：更差

5 次平均 AUC 0.702、交付 3/20，比大多数单次还差。

### ④ 无脸照片排最后：AUC 涨了，交付没动

AUC 0.723 → 0.744，但五次扫描的交付完全相同（4,4,3,3,4）——
那 30 张本来就进不了前 20。**这是正确性改进，不是效果改进**，已在代码里标注。

## 四、同组上限 2 是对的，而且有机制解释

## 五、天花板在哪，以及为什么

20 张金标在当前排序下的名次：

```
1, 9, 13, 20, 21, 30, 33, 64, 76, 79, 80, 98, 105, 106, 108, 139, 172, 205, 216, 236
中位 80/309 · 前 20 内 4 张 · 前 50 内 7 张 · 前 100 内 12 张
```

**八张金标排在 139 名之后。任何对这个信号的重排都够不着它们。**

组内排序的诊断更直接：17 张金标落在多成员场景组里，
其中只有 11 张排在组内前 2 —— **命中率 65%，随机基线 47%。**

大组里第二张金标常排在第 5、6、8、14 位：

```
F7  (7张)   ·★··★··
F13 (10张)  ★····★····
F17 (15张)  ··★··········★·
F31 (14张)  ★······★······
```

**这正是「同一个瞬间的连拍里哪张更好」这个问题**，而 Apple 的人脸质量
测的是拍摄技术质量，看不见表情、眼神、互动。

---

## 六、结论

**本地信号在人像上已经榨干了。** 剩下的差距不是调参能补的：

- 排在 139 名之后的 8 张，需要理解「这是个好瞬间」
- 组内第 5–14 位的那几张，需要「这两张近乎相同的照片里哪张更好」

这两件事恰好是 v4 设计里**分配给 VLM 但从未实现**的部分。
而且第二件事正是 v3 的 AB/BA 双向盲比想解决的问题 ——
v3 失败是因为把它用在了绝对打分上，不是因为成对比较本身不成立。

**下一步（阻塞于 MiniMax 额度）**：

1. **组内成对比较实验**（约 30 组 / 60 次调用）——
   只在含多张候选的场景组内部问「这两张哪张更好」。
   这是本地信号最确定的短板，也是成本最低的验证。
2. **否决门误杀率实验**（约 40 次调用）—— 上线前必须先测。

在这两个实验做完之前，人像这条线的诚实结论是：
**3–4/20，显著性不稳定，比随机好约 2.8 倍，成本为零。**
